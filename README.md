## ✨ Features

* ▶️ **Play / Pause** — Play and pause the current song.
* ⏹️ **Stop** — Stop the current song.
* ⏮️ **Previous Track** — Play the previous song.
* ⏭️ **Next Track** — Play the next song.
* 🔀 **Shuffle** — Randomly change the playback order.
* 🔁 **Repeat** — Repeat the current song.
* ⏩ **Seek** — Change the current playback position.
* 🔊 **Volume Control** — Adjust the audio volume.
* 🔇 **Mute / Unmute** — Mute or restore the audio volume.
* 📱 **Responsive Design** — Works across different screen sizes.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YasinTorkzaban/Music-Player.git
```

Navigate to the project directory:

```bash
cd Music-Player
```

Install the dependencies:

```bash
npm install
```

Run the project using your preferred local development server.

## 🎯 Purpose

This project was created as a frontend practice project to build a functional music player and work with JavaScript audio controls, DOM manipulation, and responsive UI design.
